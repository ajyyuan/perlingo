# Perlingo

A browser app for learning Spanish, French, and German in parallel.

Run `npm run dev`, then open http://127.0.0.1:5173. Guest preview needs no install or API key. Optional accounts require the [Supabase setup](docs/accounts.md); Google sign-in works locally and email login is disabled; Apple production sign-in and page-reload persistence are verified. The app is live at https://perlingo.app with the existing Sites address retained.
Run `npm test` and `npm run check` for validation.

The home screen offers due reviews first; otherwise it opens on a new concept. Settings presents account status, answer sound, and languages as a compact list with subtle dividers. Manage account contains sync, recovery export, and sign-out actions; pending progress choices stay visible. Concept counts and review rules are tucked under Session structure. For new material, study unseen translations side by side, then type them from English prompts in shuffled order. Due reviews skip learning cards and go directly to recall. Reviews get one attempt, with corrections after misses. New material requires a perfect full round; a miss or “I don’t know” requires another full round of the new material.

Typed recall compares against the taught form and any explicitly authored accepted alternatives, ignoring capitalization, whitespace, sentence punctuation, and curly versus straight apostrophes. Articles, accents, and spelling still matter; accented-letter buttons are provided. This is a deterministic starter-bank checker, not a general translation evaluator: unlisted valid alternatives are not accepted. The course includes a limited set of explicit alternatives; the starter bank still has one taught answer. Enter checks the answer, then continues after feedback. Blank submissions are not scored. Pronunciation uses browser speech synthesis and available device voices.

The default experience is the full 16-unit course. The legacy starter bank, available explicitly at `?pack=starter`, has 34 concepts with 102 translations. It is finite, manually authored content, not an automatically generated curriculum. Verbs start with infinitives; sentences provide selected conjugated examples. Each app-day prioritizes due pairs across units, then admits up to nine new concepts from the selected unit within a 108-answer budget. Review pressure reduces or pauses new material.

Guest progress, settings and unfinished days are saved to localStorage on the current browser and origin. The published C8 integration adds optional Supabase account sync once configured; Google/Apple-only UI is implemented; Google login is verified; Apple production sign-in and reload persistence are verified; phone/computer sync and offline conflict recovery are verified. Export progress downloads JSON. Each concept/language pair follows **4 → 32 → graduate** in app-days: learn on day 1, review on day 5, review on day 37, then stop automatic reviews. A review miss resets to +4. Completing the planned reviews and new material advances one app-day; real time does not. The 108 cap excludes extra new-material retry attempts. Existing elapsed-time progress is backed up and migrated (overdue pairs due on day 1; others day 5). See [scheduling and migration](docs/spaced-review.md).

Source: `src/content.js` (curriculum), `src/app-days.js` (day planning and scheduling), `src/engine.js` (shared/legacy helpers), `src/app.js` (interface), `src/style.css` (design). `dist` holds the static publication copy. Guest use stores no server-side application data. Configured account sync stores private per-user progress snapshots in Supabase.

During learning, click a grammatical learning chunk to pronounce it and open a contextual popover. Articles stay with nouns, multiword verb constructions stay together, and fixed expressions remain intact. The grammar cue opens the Grammar overlay with sentence context and selectable individual words; the lesson does not move. The structured packs include word roles, base forms, gender, singular/plural forms, and conjugation tables with supplied tense selection and the selected person highlighted; legacy entries explicitly identify missing word-level data. Speaker buttons play the full translation. Escape, outside click, or the close button dismiss the popover. During recall, this help becomes available on the revealed correct translation only after submission.
