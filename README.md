# Perlingo

A browser app for learning Spanish, French, and German in parallel.

Run `npm run dev`, then open http://127.0.0.1:5173. No install or API key required.
Run `npm test` and `npm run check` for validation.

The home screen offers due reviews first; otherwise it opens on a new concept. Use Settings to choose languages; persistent concept counts are tucked under the collapsed Session structure section. For new material, study unseen translations side by side, then type them from English prompts in shuffled order. Due reviews skip learning cards and go directly to recall. Reviews get one attempt, with corrections after misses. New material requires a perfect full round; a miss or “I don’t know” requires another full round of the new material.

Typed recall compares against the taught form and any explicitly authored accepted alternatives, ignoring capitalization, whitespace, sentence punctuation, and curly versus straight apostrophes. Articles, accents, and spelling still matter; accented-letter buttons are provided. This is a deterministic starter-bank checker, not a general translation evaluator: unlisted valid alternatives are not accepted. The course includes a limited set of explicit alternatives; the starter bank still has one taught answer. Enter checks the answer, then continues after feedback. Blank submissions are not scored. Pronunciation uses browser speech synthesis and available device voices.

The default experience is the full 16-unit course. The legacy starter bank, available explicitly at `?pack=starter`, has 34 concepts with 102 translations. It is finite, manually authored content, not an automatically generated curriculum. Verbs start with infinitives; sentences provide selected conjugated examples. Each app-day prioritizes due pairs across units, then admits up to nine new concepts from the selected unit within a 108-answer budget. Review pressure reduces or pauses new material.

Progress, settings and unfinished days are saved to localStorage on the current browser and origin, without cross-device sync. Export progress downloads JSON. Each concept/language pair follows **4 → 32 → graduate** in app-days: learn on day 1, review on day 5, review on day 37, then stop automatic reviews. A review miss resets to +4. Completing the planned reviews and new material advances one app-day; real time does not. The 108 cap excludes extra new-material retry attempts. Existing elapsed-time progress is backed up and migrated (overdue pairs due on day 1; others day 5). See [scheduling and migration](docs/spaced-review.md).

Source: `src/content.js` (curriculum), `src/app-days.js` (day planning and scheduling), `src/engine.js` (shared/legacy helpers), `src/app.js` (interface), `src/style.css` (design). `dist` holds the static publication copy. No server-side application data is stored.

Interaction design: [Learning chunks and contextual explanations](docs/learning-chunks.md) defines translation grouping, contextual glosses, popover behavior, and future extensions.

During learning, click a grammatical learning chunk to pronounce it and open a contextual popover. Articles stay with nouns, multiword verb constructions stay together, and fixed expressions remain intact. The grammar cue opens the Grammar overlay with sentence context and selectable individual words; the lesson does not move. The structured packs include word roles, base forms, gender, singular/plural forms, and conjugation tables with supplied tense selection and the selected person highlighted; legacy entries explicitly identify missing word-level data. Speaker buttons play the full translation. Escape, outside click, or the close button dismiss the popover. This help is not available during recall.

Learning-card navigation (C6.1): Right/Down moves forward, Left/Up moves back, with a brief upward/downward entrance on the incoming card. No Tab sequence or automatic prompt focus is required. Native Tab access remains available. These shortcuts and card movements apply only to learning; recall is unchanged. Reduced Motion disables movement. See [controls and testing](docs/keyboard-navigation.md).

Learning cards have a full-width bottom navigation panel: left ↑ goes back, right ↓ advances (or opens a ready screen on the last card). Each half is one large button; the first card disables ↑. Recall retains its existing controls.

After learning, a compact **Recall · Ready?** card pauses before the test. Right/Down or the ↓ half starts recall; Left/Up or ↑ returns to the final learning card. A held arrow cannot skip the pause; release and press again to proceed. This applies to learn-first lessons, including one-card lessons; contrast/transfer and subsequent recall rounds keep their existing flow.

IPA guides: Quick meaning shows clickable approximate IPA. Clicking it opens a separate Pronunciation overlay with playable vowel/consonant reference charts using locally bundled human recordings from Wikimedia Commons, language filters, clickable transcription sounds, a vowel quadrilateral, a consonant grid, and compact per-recording credits. Stress/length marks explain notation; French œ̃ currently has no recording. German IPA uses a context-sensitive uvular-r profile (ʁ for consonantal r, ɐ for vocalized r), with matching recordings; browser whole-word voices remain independent. Quick meaning omits the repeated word. Grammar contains grammar and context, without pronunciation content or standing source/draft notices; grammar labels open floating explanations. Source and quality information remains in About and review tooling. Recall remains free of IPA hints. See [source, coverage, regeneration and tests](docs/pronunciation.md).
