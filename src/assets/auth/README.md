# Provider sign-in assets

Downloaded from the official providers on 2026-10-19. Logos and labels are unmodified; images retain their aspect ratios and equal 44px display heights. Buttons use the existing Supabase OAuth flow.

- Google: https://developers.google.com/identity/branding-guidelines and https://developers.google.com/static/identity/images/signin-assets.zip — Android + Web, light, square, text included, PNG @4x.
- Apple: https://appleid.cdn-apple.com/appleid/button?color=white&border=true&height=44&width=200&type=sign-in&border_radius=4&scale=3 — official button image service. Guidance: https://developer.apple.com/sign-in-with-apple/usage-guidelines-for-websites-and-other-platforms/
