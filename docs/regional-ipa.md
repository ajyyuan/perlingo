# Regional IPA — deferred

The source-based regional adaptation experiment was removed at the user’s request. IPA now uses the original shared eSpeak baseline for each language; region and voice choices affect Azure audio only. The comparison page shows that baseline once beneath each word, rather than repeating a potentially misleading transcription under country columns.

Future work: derive and review transcriptions against individual recordings, key verified results to audio assets, and distinguish unverified guides. No voice-matched or regional IPA is currently implemented. The previous automatic regional rules and their runtime/chart wiring have been removed.
